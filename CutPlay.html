長い動画から残したい場面を取り置き、好きな順番につなげて保存。CutPlay の使い方や、お困りのときの対処をご案内します。

使い方よくある質問お問い合わせプライバシー

まずは、3つのステップ。

  1. 動画を選ぶ「カット編集」の動画選択ボタンから、写真ライブラリ／ギャラリーの動画を選びます。
  2. カットして取り置く3倍速などで確認し、残したい場面の前後で分割。「取り置き」でクリップを残します。
  3. つなげて保存「保存」タブでクリップを結合したい順にタップ。プレビューを確認して保存します。

フォア・バックなどのラベルや、取り置きボタンの長押しで付くバッジを使うと、お気に入りのラリーを整理できます。

iPhone は iOS 17 以降、Android は Android 10 以降が対象です。機能や画面の詳細は、利用中のバージョンにより異なる場合があります。

よくある質問

編集した動画が保存できません。

端末の空き容量を確認してください。iPhone は写真ライブラリへの追加の許可も必要です。設定アプリの CutPlay の写真アクセス設定を確認し、保存時に許可を求められた場合は許可してください。書き出し中はアプリを開いたままにしてください。

保存した動画はどこにありますか？

iPhone は写真アプリ、Android はギャラリーの Movies/CutPlay フォルダに保存されます。旧バージョンで保存した動画は Movies/EditMovie に残っている場合があります。

元の動画も切り取られますか？

元の動画は変更しません。編集のためにアプリ内へコピーし、残す区間の情報を管理します。完成した動画は別の動画として保存します。

操作を間違えました。

カット編集画面の「元に戻す」で、分割・削除・取り置きを取り消せます。編集途中の状態や取り置き動画は端末内に保存され、アプリを閉じても続きから再開できます。

ログインや会員登録は必要ですか？

必要ありません。動画の編集は端末内で行います。CutPlay は動画を開発者のサーバーに送信しません。

アプリを削除すると動画は消えますか？

アプリ専用の保存領域にある編集途中の状態、取り置き情報、元動画のコピーは削除されます。写真アプリやギャラリーへ書き出した完成動画は残ります。必要な動画を保存してからアプリを削除してください。

プライバシーポリシー

制定日：2026年11月18日 · 開発者：Tomochi

本ポリシーは動画編集アプリ CutPlay（旧表示名 EditMovie）に適用されます。

1. 情報の収集と送信

本アプリは個人情報や利用状況を開発者のサーバーに収集しません。広告・利用状況の分析ツールも使用しません。動画の編集は端末内で行い、動画を開発者や第三者のサーバーへ送信しません。

2. 動画と端末内のデータ

利用者が選択画面で選んだ動画を読み込み、編集用のコピー、取り置きクリップの情報、ラベル、バッジ、サムネイル、編集途中の状態と設定を端末内に保持します。これらは編集を再開するために使用します。不要な取り置きクリップはアプリ内で削除できます。

3. 写真ライブラリ・ギャラリーへの保存

利用者が保存操作をしたとき、編集した動画を写真ライブラリまたはギャラリーへ保存します。iPhone では写真ライブラリへの追加の許可を求めます。OS の設定画面で権限を変更できます。

4. データの削除とバックアップ

アプリを削除するとアプリ専用の保存領域にあるデータも削除されます。写真ライブラリやギャラリーに保存した動画は残るため、不要な場合は写真アプリ等から削除してください。iCloud 同期や端末のバックアップなどは利用者の OS・アカウント設定に従います。

5. 第三者への提供

開発者は本アプリを通じて個人情報を収集せず、第三者への提供・販売も行いません。

6. サポートサイトとお問い合わせ

このページ自体にアクセス解析や広告用スクリプトは設置していません。サイトは GitHub Pages を利用し、お問い合わせは GitHub Issues で受け付けます。サイトへのアクセスやお問い合わせ時の情報は、GitHub のサービスとプライバシーポリシーに従って取り扱われます。GitHub のプライバシーポリシーもご確認ください。

7. 変更と連絡先

本ポリシーを変更する場合、このページで内容と更新日をお知らせします。お問い合わせは、上記の Tomochi の問い合わせ窓口へお願いします。
