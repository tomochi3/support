# Tomochi アプリサポート

GitHub Pages の公開元は `main` ブランチの `/ (root)` です。トップページから各アプリのサポートページを開けます。

| アプリ | フォルダ | サポートURL | プライバシーポリシー |
| --- | --- | --- | --- |
| AutoCut | `autocut/` | [サポート](https://tomochi3.github.io/support/autocut/) | [ポリシー](https://tomochi3.github.io/support/autocut/#privacy) |
| CutPlay | `cutplay/` | [サポート](https://tomochi3.github.io/support/cutplay/) | [ポリシー](https://tomochi3.github.io/support/cutplay/#privacy) |

旧URLの `CutPlay.html` は、新しいページへ転送します。

お問い合わせは [GitHub Issues](https://github.com/tomochi3/support/issues) で受け付けます。投稿は一般公開です。
